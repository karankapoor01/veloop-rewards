# VELOOP Rewards

A modern, responsive, and interactive rewards platform frontend built with React.js and Vite.

VELOOP Rewards is designed with a premium fintech and rewards-focused visual style. The project contains five responsive feature banners, each with its own visual identity while maintaining a consistent VELOOP Rewards design system.

## Project Overview

The purpose of this project is to create premium, modern, trustworthy, and engaging reward-based banners for the VELOOP Rewards platform.

The project includes five main banners:

1. Leaderboard Banner
2. Watch Ads & Earn Banner
3. Contact Us Banner
4. Follow & Earn Banner
5. Daily Bonus Banner

Each banner communicates the feature, its value, and the relevant user action through a clear call-to-action.

## Banners

### 1. Leaderboard Banner

The Leaderboard Banner introduces the competitive ranking experience.

Features:

- Trophy and achievement visual
- Ranking cards
- Gold, silver, and bronze elements
- XP and reward information
- Animated visual elements
- View Leaderboard CTA

### 2. Watch Ads & Earn Banner

The Watch Ads & Earn Banner communicates the process of watching eligible advertisements and earning rewards.

Features:

- Video and advertisement visual
- Play button
- Reward visualization
- Watch → Complete → Earn flow
- Animated reward elements
- Watch & Earn CTA

### 3. Contact Us Banner

The Contact Us Banner provides a friendly and trustworthy support experience.

Features:

- Support chat interface
- Support agent visual
- Chat messages
- Online status
- Typing animation
- Contact Support CTA

### 4. Follow & Earn Banner

The Follow & Earn Banner encourages users to stay connected with VELOOP Rewards through official social channels and participate in eligible social campaigns.

Features:

- Instagram
- Facebook
- YouTube
- LinkedIn
- Telegram
- Social profile interface
- +500 SVEs reward visualization
- Floating social icons
- Explore Channels CTA

### 5. Daily Bonus Banner

The Daily Bonus Banner promotes recurring daily reward opportunities and encourages users to return regularly.

Features:

- Daily reward visualization
- Bonus information
- Reward-focused interface
- Smooth animations
- Claim Bonus CTA
